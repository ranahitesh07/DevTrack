# DevTrack

Developer Productivity Platform built with FastAPI, React, PostgreSQL and Docker.

## Tech Stack

- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic
- JWT Authentication
- React (Coming Soon)
- Docker (Coming Soon)

## Features

- User Registration
- JWT Authentication
- Login
- Protected Routes
- PostgreSQL Database

## Run Backend

```bash
cd backend

pip install -r requirements.txt

uvicorn app.main:app --reload
```

Open:

```
http://127.0.0.1:8000/docs
```
